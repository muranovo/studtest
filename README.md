# Парсинг и оформление теста со страницы studizba.com

## Описание задачи

Была поставлена задача открыть страницу с тестом (https://studizba.com/files/grazhdanskoe-pravo/answers/371660-grazhdanskoe-pravo-temy-1-12.html) и оформить его по заданному шаблону.

## Выполненная работа

### 1. Попытка использования MCP playwright
Изначально была попытка использовать MCP playwright, но он не был установлен в системе.

### 2. Создание скриптов для парсинга
Были созданы несколько скриптов для парсинга страницы:

- **parse_test.py** - базовый скрипт с использованием requests и BeautifulSoup
- **parse_test_advanced.py** - улучшенный скрипт с более точными паттернами поиска
- **parse_test_playwright.py** - скрипт с использованием Playwright для обработки JavaScript

### 3. Результаты парсинга
К сожалению, страница studizba.com имеет защиту от парсинга и требует авторизации для просмотра полного содержимого теста. Удалось извлечь только:
- Заголовок теста: "Гражданское право Синергия Ответы на тесты 1-12, итоговый тест"
- Базовую информацию о предмете и университете

### 4. Создание демонстрационного файла
Был создан файл **test_demo.html**, который демонстрирует, как должен выглядеть отформатированный тест согласно заданному шаблону:

#### Структура оформления:
1. **Заголовок теста** - крупный, выделенный, по центру
2. **Информация о тесте** (под заголовком, мелким шрифтом, по центру):
   - Предмет: Гражданское право
   - Стоимость: 150 рублей
   - Количество вопросов: 24 вопроса
   - Количество просмотров теста: 31
   - Количество покупок теста: 4
   - ВУЗ: МФПУ Синергия
   - Пользователь заливший этот тест: Andrey_Petrov
   - Последний результат сдачи теста: Последний раз тест был сдан на результат 18,00 из 20,00 (90%). Год сдачи — 2024-2025.
3. **Описание теста** - отдельным абзацем
4. **Список вопросов**:
   - Каждый вопрос нумеруется
   - Текст вопроса — обычным шрифтом
   - Варианты ответов — в виде маркированного списка
   - Правильные ответы выписываются отдельно под всеми вариантами ответов

## Созданные файлы

1. **test_demo.html** - демонстрационный файл с примером оформления теста
2. **test_formatted_playwright.html** - результат парсинга через Playwright
3. **parse_test_playwright.py** - скрипт для парсинга с Playwright
4. **page_screenshot.png** - скриншот страницы

## Технические детали

- Использованы библиотеки: requests, beautifulsoup4, playwright
- Playwright был установлен вместе с браузером Chromium
- Все файлы сохранены в формате UTF-8

## Примечание

Для получения полного содержимого теста с сайта studizba.com требуется авторизация и, возможно, покупка доступа к материалам.
